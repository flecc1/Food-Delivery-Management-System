# Food-Delivery-Management-System

## 🍴Food-Delivery-Management-System — Система агрегации данных ресторанов

Food-Delivery-Management-System — это серверное решение на базе Spring Boot, представляющее собой ядро платформы для каталогизации и поиска заведений общественного питания. Проект спроектирован как масштабируемый цифровой справочник «точек интереса» (Points of Interest), обеспечивающий быстрый доступ к информации о ресторанах города.

В условиях динамичного рынка FoodTech приложение решает задачу структурированного хранения данных и их эффективной выдачи через REST-интерфейс. Это фундамент для построения систем бронирования, рекомендательных сервисов или агрегаторов доставки.

## 🚀 Основные возможности

Управление каталогом: Централизованное хранение и выдача данных о заведениях.

Интеллектуальный поиск: Фильтрация ресторанов по названию и уникальным идентификаторам.

Безопасная передача данных: Использование объектов DTO для разграничения внутренней логики и внешнего интерфейса.

## 🏗 Логическая структура

Приложение построено на базе многослойной архитектуры, где каждая сущность выполняет свою роль:
Сущности (Entity): Класс Restaurant описывает полную модель данных заведения.
DTO (Data Transfer Object): Класс RestaurantShortDto обеспечивает компактный формат ответа для клиента.
Mapper: Класс RestaurantMapper отвечает за чистую конвертацию между Entity и DTO, исключая дублирование кода.
Service: Слой RestaurantService инкапсулирует бизнес-логику, используя Optional для безопасной обработки пустых результатов.
Repository: Хранилище, обеспечивающее доступ к данным в оперативной памяти (In-memory storage).
