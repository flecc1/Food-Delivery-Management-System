# Food-Delivery-Management-System

#🍴 FoodMap API — Система агрегации данных ресторанов

FoodMap API — это серверное решение на базе Spring Boot, представляющее собой ядро платформы для каталогизации и поиска заведений общественного питания. Проект спроектирован как масштабируемый справочник «точек интереса» (Points of Interest), обеспечивающий быстрый доступ к информации о ресторанах города.
🚀 Основные возможности

    Управление каталогом: Централизованное хранение и выдача данных о заведениях.

    Интеллектуальный поиск: Фильтрация ресторанов по названию и уникальным идентификаторам.

    Безопасная передача данных: Использование объектов DTO для разграничения внутренней логики и внешнего интерфейса.
